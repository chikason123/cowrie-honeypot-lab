 Cowrie Honeypot Lab

This project shows a simple hands-on cybersecurity lab where I deployed a Cowrie SSH honeypot and monitored attack activity in a virtual environment.

Tools Used
- Ubuntu Server
- Kali Linux
- Cowrie Honeypot
- Nmap
- Wireshark

 What I Did
I installed and ran a Cowrie SSH honeypot on an Ubuntu Server. From a Kali Linux machine, I scanned the target using Nmap and connected to the SSH service to simulate attacker behavior. While this was happening, I captured the network traffic using Wireshark.

 What I Learned
This lab helped me understand how honeypots work, how attackers interact with exposed services, and how network traffic looks during SSH activity. It also improved my documentation and reporting skills.
